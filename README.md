# 程序启动台

在 macOS 上打开的全屏应用网格。点图标启动程序，成功后窗口收起，程序留在程序坞里。可以搜索、翻页、放进文件夹、拖拽排序，并调节图标大小。

这不是系统自带的启动台。程序坞和「应用程序」里的名字是「程序启动台」。

## 运行环境

macOS 14 或更高版本，以及 Swift 命令行工具。

## 打开

在项目目录执行：

```bash
Scripts/package-app.sh
open MacLaunchpad.app
```

打包时会带上应用图标。也可以先不打包，直接运行：

```bash
swift run MacLaunchpad
```

按 Command-Q 退出。窗口收起后进程还在，再从程序坞点一次就会重新打开。

## 使用

- 打开后直接打字即可搜索，不会弹出输入法候选条。也可以用鼠标点进搜索框，这时可以用中文输入法输入。搜索只过滤当前画面，不改已保存的排列。退格删掉最后一个字。搜索框空着时，左右方向键仍可翻页。
- 搜索时按回车，打开结果里的第一个应用。输入法正在拼字时，回车先交给输入法。
- 用鼠标左右拖动整页翻页，松手后吸附到相邻页。触控板左右滑、鼠标滚轮、方向键和底部圆点也可以翻页。
- 在图标上按住约半秒再拖，可以换位。拖到另一个图标中心会建成文件夹。
- 点图标之间或壁纸上的空白处会收起窗口，和系统启动台一样。搜索框、页码圆点和左下角的大小滑块不算空白。文件夹打开时，点外面的暗处只关上文件夹。
- 按 Esc：正在输入文件夹名字时取消改名；正在搜索时清空搜索；开着文件夹时关上文件夹；否则收起窗口。
- 左下角可以调节图标大小，这个大小会记住。图标变大后，一页能放下的数量会减少，并按新容量重新分页。

排列保存在 `~/Library/Application Support/MacLaunchpad/layout.json`。每次打开都会重新扫描本机应用，包括用户应用目录、`/Applications`、`/System/Applications`（含实用工具）以及 Homebrew Cask 安装的应用。
